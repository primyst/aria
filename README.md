# Hero Showcase

Five standalone hero-section explorations, built to screen-record for a
motion-design reel. Not production, just visual references.

## Routes

- `/architecture`
- `/fashion`
- `/technology`
- `/real-estate`
- `/experimental`

## Run it

```bash
npm install
npm run dev
```

Open `http://localhost:3000` for an index of all five, or jump straight to
a route, e.g. `http://localhost:3000/architecture`.

Images are pulled live from Unsplash, so you'll need an internet connection.
